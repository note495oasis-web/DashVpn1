# DashVPN

[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-orange.svg)](https://www.gnu.org/licenses/gpl-3.0)

DashVPN — VPN-клиент для Android с встроенной подпиской серверов и тёмным интерфейсом.

DashVPN is an Android VPN client with a built-in server subscription and a dark UI.

## Основано на / Based on

DashVPN основан на [NekoBox for Android](https://github.com/MatsuriDayo/NekoBoxForAndroid) (MatsuriDayo).
Ядро — [SagerNet/sing-box](https://github.com/SagerNet/sing-box).

DashVPN is based on [NekoBox for Android](https://github.com/MatsuriDayo/NekoBoxForAndroid) by MatsuriDayo,
powered by [sing-box](https://github.com/SagerNet/sing-box).
